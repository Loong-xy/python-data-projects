# LA Building Permits Analytics & Contractor Dashboard

This project analyzes building permit activity in Los Angeles to
identify trends in construction, contractor behavior, and permit
processing dynamics.

## Overview
- Designed an end-to-end analytics workflow combining SQL-style logic
  and Python analysis
- Explored permit trends by project type, geography, and contractor
- Built an interactive dashboard to surface contractor-level insights
- Focused on actionable insights for homeowners, planners, and analysts

## Tools
Python, pandas, matplotlib, SQL-style analytics, dashboard development

> Note: This project is adapted from coursework and rewritten for
> demonstration purposes. Original datasets were accessed via a
> cloud platform and are not publicly shared.
