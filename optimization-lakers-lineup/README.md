# Lakers Lineup Optimization

This project applies optimization modeling techniques to construct
optimal basketball lineups under performance and structural constraints.

## Overview
- Formulated lineup selection as an optimization problem
- Defined decision variables, objectives, and constraints
- Implemented the model in Python with modular design
- Extended the model with a simple GUI for interaction


## Tools
Python, pandas, numpy, optimization modeling

> Note: This project is adapted from coursework and rewritten for
> demonstration purposes. Problem statements and data have been modified.
