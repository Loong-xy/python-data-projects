# Monte Carlo Simulation for Project Risk

This project applies Monte Carlo simulation to quantify project cost
uncertainty and support risk-aware decision-making.

## Overview
- Simulated thousands of possible cost outcomes
- Estimated P50 and P90 values for contingency planning
- Visualized risk distributions and interpreted results

## Business Impact
- Provided a data-driven recommendation for contingency buffers
- Improved risk transparency for project stakeholders

## Tools
Python, numpy, pandas, matplotlib
