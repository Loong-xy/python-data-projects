# Retail Sales Analytics Dashboard

This project analyzes retail sales data and presents key business
insights through an interactive analytics dashboard.

## Overview
- Cleaned and transformed transactional sales data
- Analyzed product and keyword-level performance
- Built visual dashboards to track sales trends and drivers
- Designed an end-to-end analytics workflow from raw data to insights

## Key Features
- Sales trend and performance analysis
- Keyword-based product insights
- Interactive dashboard for business users

## Tools
Python, pandas, matplotlib, streamlit (or similar)

> Note: This project is adapted from coursework and rewritten for
> demonstration purposes. Data has been anonymized or sampled.
