# MLB Team Performance Analysis & Data Wrangling

This project analyzes MLB team batting and pitching performance across
multiple seasons using structured data wrangling and exploratory analysis.

## Overview
- Cleaned and standardized raw batting and pitching datasets
- Integrated data across seasons for comparison
- Analyzed team-level performance trends
- Prepared analysis-ready datasets for downstream modeling

## Key Skills Demonstrated
- Data cleaning and transformation
- Multi-source dataset integration
- Exploratory data analysis (EDA)
- Clear analytical workflow in Python

## Tools
Python, pandas, numpy

> Note: This project is adapted from coursework and rewritten for
> demonstration purposes. Datasets have been anonymized or sampled.
