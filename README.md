# Python Data & Analytics Projects

This repository contains selected Python projects from graduate-level
coursework and case competitions, focusing on data analytics, optimization,
and risk modeling.

## Projects

### 1. Lakers Lineup Optimization
- Linear optimization model for decision-making under constraints
- Implemented in Python
- Focus on formulation, constraints, and objective design

### 2. Algorithmic Thinking – Snowflake Problem
- Algorithm design and structured problem-solving
- Emphasis on clean, modular Python implementation

### 3. Monte Carlo Simulation for Project Risk
- Simulated project cost uncertainty using Monte Carlo methods
- Estimated P50 / P90 outcomes for risk-aware decision-making
- Visualized distributions and interpreted results

## Tools & Skills
Python, pandas, numpy, optimization modeling, statistical analysis
