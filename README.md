# Python Data & Analytics Projects

This repository contains selected Python projects from graduate-level
coursework and independent case projects, focusing on data analytics,
optimization, risk modeling, and business decision support.

The projects emphasize end-to-end analytical workflows, from data
preparation and modeling to visualization and practical insights.

---

## Projects

### 1. Lakers Lineup Optimization
- Formulated lineup selection as a constrained optimization problem
- Designed decision variables, objectives, and constraints
- Implemented a modular Python solution with an interactive interface
- Demonstrates optimization modeling and structured problem-solving

### 2. Monte Carlo Simulation for Project Risk
- Modeled project cost uncertainty using Monte Carlo simulation
- Estimated P50 / P90 risk metrics for contingency planning
- Visualized distributions and translated results into decision insights
- Applied risk modeling techniques commonly used in finance and operations

### 3. MLB Team Performance Analysis & Data Wrangling
- Cleaned and integrated multi-season batting and pitching datasets
- Standardized messy real-world data for analysis
- Conducted exploratory analysis of team-level performance trends
- Demonstrates strong data wrangling and analytical foundations

### 4. Retail Sales Analytics Dashboard
- Analyzed retail transaction data and product-level performance
- Built exploratory visualizations to uncover sales drivers
- Developed an interactive dashboard to present insights to business users
- Demonstrates analytics delivery beyond notebooks

### 5. LA Building Permits Analytics & Contractor Dashboard
- Designed an end-to-end analytics workflow for public-sector data
- Analyzed permit activity and contractor behavior
- Built a dashboard to surface contractor-level insights
- Demonstrates cloud-style analytics, SQL logic, and dashboard development
